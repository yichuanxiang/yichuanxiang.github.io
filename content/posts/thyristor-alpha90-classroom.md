这次围绕一个问题整理课堂演示：**三相桥式全控整流电路采用纯电阻负载、触发角 α=90° 时，VT1 两端的电压应该怎样画？**

先确定课堂采用的条件。教师课件图 3-26 没有画外接 RC，并在断流区间把两个直流公共端的对中性点电位画成零。**按这个课件理想约定，断流时 uVT1=ua。** 下面同时展示另一套额外接入六条 RC 的电路仿真，用来解释：为什么补充了不同电路条件，关断电压也会变化。

两种图有同一个起点：**uVT1=ua−ud1**。先找 VT1 阳极和阴极的电位，再取差值，就能把各段波形串起来。

## 先认清电路和电压方向

![清晰的三相全控桥：上桥臂 VT1、VT3、VT5 接 a、b、c 相，下桥臂 VT4、VT6、VT2 接对应相，右侧为电阻负载。](/images/thyristor-alpha90/clear_bridge_circuit.png)

*这是用于仿真的清晰版电路，六个晶闸管子系统内各含一条外接串联 RC 吸收支路；课件原图没有画这些支路。*

所有节点电位均以电源中性点 **N** 为参考。上桥臂公共端为 **d1**，下桥臂公共端为 **d2**，电阻负载接在两者之间。VT1 的阳极接 a 相，阴极接 d1，电压方向取**阳极减阴极**。

用 U 表示相电压有效值，用 Um=√2U 表示相电压峰值，则：

| 符号 | 含义 |
| --- | --- |
| ua、ub、uc | 三相相电压，对中性点 N |
| uab=ua−ub、uac=ua−uc | 对应的线电压 |
| ud1、ud2 | 两个直流端对 N 的电位 |
| ud=ud1−ud2 | 负载两端的电压 |
| uVT1=ua−ud1 | VT1 阳极到阴极的电压 |
| ux≈ud1≈ud2 | 断流区间两直流端接近时的公共电位 |

电压是两个节点电位的差，选择参考点后，才能谈某个节点“为正”“为负”或“为零”。这是节点电位分析的基本方法。[MIT：Review of Network Theory，第 5 页](https://ocw.mit.edu/courses/6-061-introduction-to-electric-power-systems-spring-2011/d79822ef5fbdb21b1c44e1b3b8282453_MIT6_061S11_ch1.pdf)

## α=90°时，电流为什么会中断

对于这里的纯电阻负载，忽略器件的小压降时，id=ud/R。导通的两相线电压下降到零，负载电流也随之下降到零；下一对晶闸管尚未被触发，中间便出现断流区间。

在课件的理想工况下，每对管约导通 **30°**，随后约断流 **30°**，下一对管再开始导通。按本图编号，一周期中的管对顺序为：

**VT1/VT6 → VT1/VT2 → VT3/VT2 → VT3/VT4 → VT5/VT4 → VT5/VT6。**

带外接 RC 的器件模型仍表现为 SCR 主导电流断续，但有限维持电流使关断略早于理想零点，吸收支路和截止漏电也仍可能存在小电流。因此图中的“断流”要和理想零电流、所有支路完全没有电流区分开。模型采用的导通压降、截止电导和维持电流定义可查 [MathWorks：Thyristor (Piecewise Linear)](https://www.mathworks.com/help/simscape-electrical/ref/thyristorpiecewiselinear.html)。

## 导通段：看是谁钳位了 d1

分析 VT1 管压时，可以先把上桥臂分成三种状态：

| 上桥臂导通管 | d1 的电位 | VT1 管压的理想近似 |
| --- | --- | --- |
| VT1 | 跟随 a 相 | uVT1≈0 |
| VT3 | 跟随 b 相 | uVT1≈ua−ub=uab |
| VT5 | 跟随 c 相 | uVT1≈ua−uc=uac |

VT1 自己导通时，a 相与 d1 之间只剩小导通压降，所以大比例波形上画成近似零。VT3 或 VT5 导通时，d1 分别被 b 相或 c 相钳位，VT1 承受的电压就变为相应线电压。实际模型还包含器件的小压降修正。

## 断流段：课件与 RC 模型采用了不同条件

![上图为课件零公共电位约定下补画的解析示意，下图为已有六条外接 RC 电路的传感器仿真数据。](/images/thyristor-alpha90/vt1_courseware_vs_externalRC.png)

*上图是解析示意，并非新做的无 RC 电路仿真；下图是已保存的外接 RC 电路仿真结果。两幅图都不是实物测量波形。*

**按课件画法：**断流区间取 ud1=ud2=0，代入 uVT1=ua−ud1，就得到 **uVT1=ua**，沿相电压曲线画。

**在本次外接 RC 模型中：**断流时 ud1、ud2 很快接近，但共同电位 ux 没有立即变为零。所以这一段应写成 **uVT1≈ua−ux**。

这里的六条 RC 是搭建模型时额外加入的吸收支路，每条为 **500 Ω 与 250 nF 串联**，并接在一只晶闸管两端。它们不是这个原生晶闸管模型自动包含的寄生结电容，参数也没有从教师课件或指定实物器件中推得。并联 RC 会影响晶闸管两端再施加电压的变化过程，这一点有器件资料依据。[STMicroelectronics：AN4608，第 15 页](https://www.st.com/resource/ja/application_note/an4608-how-to-select-the-right-thyristor-scr-for-your-application-stmicroelectronics.pdf)

电阻负载约束的是 **ud1−ud2**。即使两端电位相等，它们也可以一起位于正电位或负电位；电阻并没有把它们连接到中性点。共同电位需要结合储存电荷、截止漏电和此前的导通状态求解。

在**三相平衡、六条相同 RC、相同截止电导、直流端未接中性点、稳态运行**的本模型中，短断流区间有 **ux≈±Um/2**，且正负交替。这个半峰值近似包含具体网络条件，不能推广成所有 α=90° 电路的通用公式。

## ux 一正一负，为什么两段管压都能为负

![分别比较两个断流区间的 ua、ux 和 uVT1；公共电位一正一负，而 VT1 电压都可下降到零以下。](/images/thyristor-alpha90/vt1_two_negative_gaps.png)

先看 VT1、VT6 导通结束时。理想关断点在 a、b 两相的正交点，按本图的相位定义：

**ua=ub=Um·sin150°=+Um/2。**

对称 RC 中的储存电荷使 ux 在随后短时间内近似保留这个正电位。ua 继续下降，变得小于 ux，于是 **ua−ux<0**。

下一对 VT1、VT2 导通结束时，关断交点位于负半周：

**ua=uc=Um·sin210°=−Um/2。**

这时 ux 近似为负，但 ua 继续下降，变得比 ux 更负，所以 **ua−ux 仍然可以小于零**。图中的 ux 正负号描述的是公共端电位，不是 VT1 管压的正负号。

例如只看半峰值理想近似，第一段在 165° 时约为 **0.259Um−0.5Um=−0.241Um**；第二段在 225° 时约为 **−0.707Um−(−0.5Um)=−0.207Um**。负数减负数是否为正，取决于两个电位谁更大。

每次新一对管导通，直流端都会重新被两相电压钳位，建立下一段的关断初值。因此下一段负 ux 来自新的导通过程，不是上一段正 ux 在断流中自行翻转。

## 上课可以按这个顺序讲

1. **先指电路。**说明 N、d1、d2 的位置，以及 VT1 的电压方向，写下 uVT1=ua−ud1。
2. **再指电流。**说明 α=90°、纯电阻负载的约 30° 导通和约 30° 断流，按顺序看六组管对。
3. **讲三个导通段。**VT1 导通近似零，VT3 导通近似 uab，VT5 导通近似 uac，原因都是对 d1 的钳位。
4. **切到两种条件的对照。**课件断流段取零公共电位，所以画 ua；额外接入 RC 的模型求得非零 ux，所以画 ua−ux。
5. **放大相邻两个断流区间。**同时比较 ua、ux 和差值，解释“公共电位一正一负，管压仍能为负”。

开场可以这样说：“我先按课件条件解释波形，再展示一套额外加了 RC 的仿真作对照。两幅图都遵循 uVT1=ua−ud1，差别在于断流时 d1 的电位采用了什么条件。”

## 几个容易被问到的问题

**电流为零，为什么管压不为零？**

负载零电流约束的是 d1 与 d2 的电位差。VT1 跨在 a 相与 d1 之间，是另外两个节点，仍然可以承受截止电压。

**没有 RC，公共电位就一定为零吗？**

要补充截止模型。完全理想的截止开路器件若没有任何电容、漏电或参考通路，共同电位缺少约束。若另行指定六条等值有限截止电导、平衡三相且没有电容等其他支路，则全截止的静态节点方程给出 ud1=ud2=0。本项目验证了这个静态等效网络；**无 RC 的完整门极控制桥切换仿真尚未通过校验**，所以不能说已经成功重仿真了无 RC 原电路。

**RC 模型中的 ux 会永远停在半峰值吗？**

不会。六管全截止、网络满足上述对称条件时，共同电位满足 **C(1+RsG)·dux/dt+Gux=0**。本参数对应衰减时间常数约 **2.5 秒**，远长于 50 Hz 下约 **1.67 毫秒**的 30° 断流区间，因此短时间内近似保留。半峰初值还忽略了小管压降、有限维持电流和边沿暂态。

**为什么不能直接套连续电流波形？**

课件图 3-30 采用连续电流条件，公共端持续由导通的上桥臂晶闸管钳位；这里讨论图 3-26 的电阻负载断续工况。分析状态不同，不能直接沿用完整 120° 导通段。

## 模型参数与验证范围

已验证的器件级仿真由 **MATLAB R2024b、Simulink、Simscape Electrical** 完成。管压由跨 VT1 的电压传感器直接取得，同时保存相电压、直流端电位和各 SCR 主支路电流。

| 项目 | 外接 RC 模型设置 |
| --- | --- |
| 三相电源 | 相电压有效值 220 V，50 Hz，相差 120°，中性点接参考地 |
| 负载 | 10 Ω 纯电阻，两个直流端均未接中性点 |
| 晶闸管 | 六只 Thyristor (Piecewise Linear) |
| 器件参数 | 导通压降 0.8 V，导通电阻 1 mΩ，截止电导 10⁻⁷ S，维持电流 0.1 A |
| 外接吸收支路 | 每只管并联串联 RC：500 Ω、250 nF |
| 触发 | α=90°，10 V 双窄脉冲，单脉冲宽 5°，两脉冲相隔 60° |
| 求解 | ode23t，基准最大步长 5 μs，细化最大步长 2.5 μs |
| 运行区间 | 从零初始电容电压求解到 0.12 秒，绘图选取末段稳态周期 |

验证记录给出了以下结果，均对应各自标明的网络与比较范围：

| 检查 | 结果与范围 |
| --- | --- |
| 电压方向与 KVL | 直接管压与 ua−ud1 最大差约 5.68×10⁻¹⁴ V |
| 步长细化 | 距开关边沿超过 3° 的区域，两解最大差约 2.46×10⁻⁴ V |
| 稳态周期重复 | 相同边沿外区域，相邻周期最大差约 4.20×10⁻¹⁰ V |
| 清晰版与原模型 | 开关边沿外最大差约 9.04×10⁻⁹ V |
| RC 模型全截止区间 | 逐段内部核对六管 i=Goff·v，并检查公共电位变化规律，通过 |
| 六等值电导静态截止对照 | ux/Um 最大绝对值约 2.87×10⁻¹⁶，通过；不是完整切换仿真 |

这些数值说明所选模型的电路关系和求解结果得到核对。模型没有按实物器件、真实吸收参数或变压器漏感校准，也没有包含真实恢复时间、非线性结电容及线路杂散电感。边沿上的尖峰、振铃和实物瞬态不能据此直接判断。

模型、绘图程序、CSV 传感器数据和验证 JSON 放在[课堂资料包](/downloads/thyristor-alpha90-classroom.zip)中。浏览器演示用于讲解和观察已有结果；重新求解物理电路需要相应 MATLAB 工具箱。
