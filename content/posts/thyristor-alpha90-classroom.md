这次课堂要讲的是 **α=90° 时 VT1 的管压**。电路为三相桥式全控整流，接纯电阻负载，电压方向取阳极到阴极。

容易混淆的是断流段。课件图 3-26 取 ud1=ud2=0；已有仿真在六只管两端各加了一条 RC，断流时的公共电位并不为零。画波形前，要先分清采用的是哪套条件。

## 电路与电压方向

![三相全控桥电路，上桥臂为 VT1、VT3、VT5，下桥臂为 VT4、VT6、VT2，右侧接电阻负载。](/images/thyristor-alpha90/clear_bridge_circuit.png)

*图中是外接 RC 的仿真模型，RC 位于各晶闸管子系统内。课件原图没有这些支路。*

电源中性点为 **N**，上、下桥臂公共端分别为 **d1、d2**。VT1 的阳极接 a 相，阴极接 d1。所有节点电位都对 N 定义：

- 管压：**uVT1=ua−ud1**。
- 负载电压：**ud=ud1−ud2**，负载电流 id=ud/R。
- 线电压：uab=ua−ub，uac=ua−uc。
- 相电压峰值：Um=√2U，其中 U 为相电压有效值。

## 导通段看 d1

电阻负载在 α=90° 时是断续导通。理想情况下，每对管导通约 **30°**，随后断流约 **30°**。本图编号下的管对顺序为：

VT1/VT6 → VT1/VT2 → VT3/VT2 → VT3/VT4 → VT5/VT4 → VT5/VT6。

线电压降到零时，id=ud/R 也降到零；下一对管还没触发，就出现了空档。RC 仿真有有限维持电流，SCR 主支路会稍早关断，截止漏电和 RC 支路仍有小电流。

对 VT1 来说，先找出正在导通的上桥臂，便能确定 d1 的电位：

| 上桥臂导通管 | ud1 的理想近似 | uVT1=ua−ud1 |
| --- | --- | --- |
| VT1 | ua | 0 |
| VT3 | ub | uab |
| VT5 | uc | uac |

所以读导通段时，记住 **0、uab、uac** 就够了。仿真器件有 0.8 V 导通压降，读数会有小修正。

## 断流段为什么有两种画法

![上图为课件零公共电位约定的解析示意，下图为六条外接 RC 电路保存的传感器仿真数据。](/images/thyristor-alpha90/vt1_courseware_vs_externalRC.png)

*上图按课件条件解析绘制，下图取自已有 RC 电路仿真。两者均非实物测量，上图也不是无 RC 电路的切换仿真。*

**课件图 3-26：**断流时取 ud1=ud2=0，因此 **uVT1=ua**，这一段沿 a 相电压画。

**外接 RC 模型：**断流时 d1、d2 很快接近，把共同电位记作 ux，则 **uVT1≈ua−ux**。

电阻只约束 d1、d2 之间的电位差，没有把这两个端点接到 N。因此负载电流为零，不代表 ud1、ud2 都为零，更不代表 VT1 管压为零。

仿真中的 RC 是额外加入的串联吸收支路，每只管并联一条 **500 Ω、250 nF** 的支路。它们不是晶闸管模型自动带入的结电容，也不是课件提供的参数。

在这套**三相平衡、六条相同 RC、相同截止电导、直流端浮置、稳态运行**的模型中，短断流区间有 **ux≈±Um/2**，符号逐段交替。新一对管导通后，公共端重新被相电压钳位，形成下一段的初值。

六管全截止时，对称网络的公共电位满足：

**C(1+RsG)·dux/dt+Gux=0。**

本参数的衰减时间常数约为 **2.5 秒**，而 50 Hz 下的 30° 只有 **1.67 毫秒**，所以短间隔内 ux 近似保持关断前的值。半峰值近似忽略了小管压降、维持电流和边沿暂态，只适用于上述网络。

还需单独区分无 RC 的截止模型：完全理想开路、又没有电容或漏电参考通路时，公共电位缺少约束。若明确指定六条等值有限截止电导，平衡三相且没有电容，**全截止静态节点方程**给出 ud1=ud2=0。这一静态等效网络已验证；完整无 RC 门极切换仿真尚未通过校验，不能用它来代替课件上图的解析说明。

## 两段 ux 符号相反，管压为什么都能为负

![相邻两个断流区间的 ua、ux 与 uVT1 对照。](/images/thyristor-alpha90/vt1_two_negative_gaps.png)

按图中的相位定义，VT1/VT6 的理想关断点在 150°：

**ua=ub=+Um/2。**

随后 ux 暂时保持在约 +Um/2，而 ua 继续下降，故 ua−ux<0。例如在 165°，约为 **0.259Um−0.5Um=−0.241Um**。

VT1/VT2 的理想关断点在 210°：

**ua=uc=−Um/2。**

这一段 ux 约为 −Um/2，但 ua 下降得更低，差值仍可为负。在 225°，约为 **−0.707Um−(−0.5Um)=−0.207Um**。

判断管压正负，要比较 ua 和 ux 谁更大，不能只看 ux 的正负号。后一段的负 ux 来自新的导通过程，不是前一段的正 ux 在断流期间自行翻转。

## 课堂上怎么指波形

1. 指出 a 相、d1 和 VT1，写下 uVT1=ua−ud1。
2. 看负载电流，标出约 30° 导通、30° 断流。
3. 沿上桥臂顺序读导通段：VT1 对应 0，VT3 对应 uab，VT5 对应 uac。
4. 读断流段：课件取 ud1=0，得到 ua；RC 模型保留 ux，得到 ua−ux。
5. 放大 150°—180° 与 210°—240°，比较 ua、ux 和两者之差。

[演示页](/classroom/thyristor-alpha90/)中，电路图和波形使用同一个时间光标：亮起的管正在导通，绿色路径表示经过负载的主电流，灰色管表示截止。可以逐段看，也可以播放一整周期。[短视频](/classroom/thyristor-alpha90/waveform-demo.mp4)录下了这套演示，前半为课件示意，后半为保存的 RC 仿真数据。

## 仿真参数与核对结果

已有电路仿真使用 **MATLAB R2024b、Simulink、Simscape Electrical**。VT1 管压来自跨管电压传感器，同时保存三相电压、直流端电位和六只 SCR 的主支路电流。

| 项目 | 设置 |
| --- | --- |
| 电源 | 相电压有效值 220 V，50 Hz，相差 120°，中性点接参考地 |
| 负载 | 10 Ω 纯电阻，直流端未接中性点 |
| 晶闸管 | 六只 Thyristor (Piecewise Linear) |
| 器件参数 | 导通压降 0.8 V，导通电阻 1 mΩ，截止电导 10⁻⁷ S，维持电流 0.1 A |
| 外接 RC | 每只管并联串联 RC：500 Ω、250 nF |
| 触发 | α=90°，10 V 双窄脉冲，宽 5°，间隔 60° |
| 求解 | ode23t；基准最大步长 5 μs，细化为 2.5 μs |
| 运行 | 电容电压从零开始，求解至 0.12 秒，取末段稳态周期绘图 |

| 核对项 | 结果 |
| --- | --- |
| 传感器管压与 ua−ud1 | 最大差约 5.68×10⁻¹⁴ V |
| 步长细化 | 距开关边沿超过 3° 的区域，两解最大差约 2.46×10⁻⁴ V |
| 相邻稳态周期 | 同样边沿外区域，最大差约 4.20×10⁻¹⁰ V |
| 清晰版与原模型 | 开关边沿外最大差约 9.04×10⁻⁹ V |
| RC 模型全截止段 | 区间内部六管 i=Goff·v 及公共电位规律核对通过 |
| 六等值电导静态对照 | ux/Um 最大绝对值约 2.87×10⁻¹⁶；仅为静态验证 |

这些结果用于检查模型内的电路关系和数值求解。模型没有按实物器件和吸收参数校准，也没有真实恢复时间、非线性结电容及线路杂散电感，不能据此判断实物边沿上的尖峰和振铃。

资料包包含模型、绘图程序、CSV 和验证 JSON；演示页查看的是这些保存结果。重新求解电路需要相应 MATLAB 工具箱。
