这台小米平板 3 退役以后，我把它改成了家里的服务器。MT8176 六核处理器，加上 4GB 内存，跑个人云盘和博客够用了。它没有风扇，放在那里也没什么动静。

现在启动的是原生 Alpine Linux。Android 的用户空间已经替换掉，硬件需要的底层固件还保留着。数据放在单独挂载的 `/srv`，没有塞进容量较小的根分区。

## 平板上跑什么

FileBrowser 用来存取个人文件。出门后，可以通过 WireGuard 连回家；维护服务器时也会用到 Tailscale 和 SSH。

博客最初也是在这台平板上搭的，用 Hugo 生成页面，主题是 PaperMod。后来我把公开版本迁到了 GitHub Pages。文章页面由 GitHub 提供，家里的平板继续跑云盘。

## 2026 年 9 月 30 日补记

这次检查时，平板已经连续运行了约 50 天，六个核心都在线，温度约 29°C。内存还有约 3.5GB 可用，数据盘剩余约 52.7GB，日常这些服务没有把它占满。

我也给博客加了一个公开附件入口。图片、视频或下载文件可以放在平板的专用目录，文章里引用它们的 HTTPS 链接。这个目录只提供读取和下载，私人云盘没有接到这个公网入口上。

这样分开以后，平板离线时文章仍然能看，只是平板上的附件会暂时打不开。
