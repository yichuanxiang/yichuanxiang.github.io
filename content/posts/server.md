## 为什么用平板做服务器

一台退役的小米平板 3，MT8176 六核处理器、4GB 内存，拿来当服务器正合适：

- **功耗低**：整机才几瓦，24 小时开机不心疼
- **性能够**：跑 FileBrowser 云盘、Hugo 博客毫无压力
- **零噪音**：没有风扇，安静得很

## 搭了什么

- **云盘**：FileBrowser，个人文件随手存取
- **博客**：最初在平板上运行，公开版本后来迁到 GitHub Pages
- **远程**：WireGuard 加密隧道，出门在外也能连回家
